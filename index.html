It started with a pull request.

I found a Minecraft project bringing elections to Towny and sent a pull request to improve it.

The creator had abandoned the project. My pull request reminded them it was there, and they archived it soon after. I noticed the next day.

I decided to start my own fork and use AI as a coding partner to carry the idea forward. That fork became Towny Elections Reborn.
